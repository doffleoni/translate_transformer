## Что переведено

Полный текст: титульный лист (авторы, примечания о вкладе, выходные данные конференции),
аннотация, разделы 1–7, благодарности, список литературы (40 позиций), приложение с
визуализациями внимания.

Список литературы оставлен в оригинальном написании — по нему ищут источники. Названия
моделей и метрик (Transformer (big), BLEU, PPL, FLOPs) сохранены узнаваемыми.

Терминология выдержана единообразно по всему документу:

| Английский | Русский |
|---|---|
| Transformer | Трансформер |
| self-attention | самовнимание |
| multi-head attention | многоголовое внимание |
| encoder / decoder | кодировщик / декодировщик |
| scaled dot-product attention | масштабированное внимание по скалярному произведению |
| residual connection | остаточное соединение |
| layer normalization | послойная нормализация |
| position-wise feed-forward network | поточечная сеть прямого распространения |
| beam search | поиск по лучу |
| dropout, perplexity, label smoothing | dropout, перплексия, сглаживание меток |

## Пересборка

Нужны Python 3.9+ и пакеты `python-docx`, `pymupdf`, `pillow`, `numpy`.

```bash
# 1. вырезать рисунки и формулы из исходного PDF в work/fig/
python3 work/crop_final.py

# 2. собрать DOCX (текст перевода — в work/content1.py, content2.py, content3.py,
#    таблицы — в work/tables.py)
python3 work/build_docx.py

# 3. получить PDF (LibreOffice или любой конвертер DOCX → PDF)
soffice --headless --convert-to pdf Attention_Is_All_You_Need_RU.docx
```

Скрипт `crop_final.py` проверяет каждую вырезку: если содержимое упирается в границу
области, он сообщает об этом и останавливается — значит прямоугольник в `CROPS` нужно
расширить.

### Структура

```
work/
├── crop_final.py     извлечение рисунков и формул из PDF плюс проверка обрезки
├── build_docx.py     сборка документа: стили, сноски, таблицы, рисунки, формулы
├── content1.py       перевод: титул, аннотация, разделы 1–3.4
├── content2.py       перевод: разделы 3.5–7, литература
├── content3.py       приложение с визуализациями внимания
├── tables.py         таблицы 1–4
└── fig/              вырезанные рисунки и формулы (PNG, 400 dpi)
```

Разметка текста в `content*.py` простая: `[[b]]…[[/b]]` — полужирный,
`[[i]]…[[/i]]` — курсив, `[[sup]]…[[/sup]]` и `[[sub]]…[[/sub]]` — над- и подстрочные
индексы, `[[m]]…[[/m]]` — математический курсив, `[[fn:N]]` — сноска номер `N`.
