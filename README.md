# translate_transformer

Профессиональный русский перевод статьи **«Attention Is All You Need»**
(Vaswani et al., NIPS 2017) — работы, в которой предложена архитектура Трансформера.

Исходник — [`1706.03762v7.pdf`](1706.03762v7.pdf) (arXiv:1706.03762v7), 15 страниц.

## Результат

| Файл | Описание |
|---|---|
| [`Attention_Is_All_You_Need_RU.docx`](Attention_Is_All_You_Need_RU.docx) | Перевод в Word: 16 страниц, 10 иллюстраций, 4 таблицы, 2 сноски |
| [`Attention_Is_All_You_Need_RU.pdf`](Attention_Is_All_You_Need_RU.pdf) | Тот же документ в PDF |

Переведено всё: титульный лист с авторами и примечаниями о вкладе, аннотация, разделы 1–7,
благодарности, список литературы (40 позиций) и приложение с визуализациями внимания.
Иллюстрации, таблицы и формулы сохранены и расставлены по смысловым привязкам в тексте.

Подробности о терминологии, расстановке иллюстраций и пересборке документа —
в [`work/README.md`](work/README.md).

## Пересборка

```bash
python3 work/crop_final.py    # вырезать рисунки и формулы из исходного PDF
python3 work/build_docx.py    # собрать DOCX из перевода в work/content*.py
```

Требуются пакеты `python-docx`, `pymupdf`, `pillow`, `numpy`.
